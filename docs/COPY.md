# מסמך קופי — רנצ'ו RideCare

כל הטקסט שמופיע באפליקציה, מסודר לפי מסכים, בדיוק כפי שהוא כתוב היום בקוד.

**איך עובדים עם המסמך:** עורכים את הטקסט כאן (או מוסיפים ליד כל שורה את הנוסח החדש) ומחזירים — כל שורה ממופה למקום אחד בקוד, כך שההחלה חזרה מהירה ומדויקת.

**שימו לב לשורות המסומנות 🔒** — יש להן משמעות עסקית/משפטית מהאפיון (שקיפות מחיר, בטיחות, אישור לפני עבודה). אפשר לשפר ניסוח, אבל המשמעות חייבת להישמר.
